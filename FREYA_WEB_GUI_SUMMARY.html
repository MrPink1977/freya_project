🚀 Quick Start

1. Install Dependencies

pip install fastapi uvicorn python-multipart jinja2

2. Launch the GUI

# Simple launch python run_web_gui.py # Custom host/port python run_web_gui.py --host 0.0.0.0 --port 8080 # Development mode python run_web_gui.py --reload

3. Open Browser

Navigate to: http://localhost:8000

4. Try It Out

  1. Click "▶️ Start" under Ollama Server
  2. Select a model from dropdown
  3. Click "📥 Load Model"
  4. Start chatting!

🔧 API Endpoints

GET / Main UI page GET /api/status Get Freya status POST /api/ollama/start Start Ollama server POST /api/ollama/stop Stop Ollama server GET /api/ollama/models List available models POST /api/ollama/load-model Load specific model POST /api/chat Send chat message GET /api/debug/logs Get debug logs GET /api/debug/agents Get agent statuses WS /ws WebSocket connection

🔌 Integration Examples

Connect DialogAgent

# In app.py from freya.infrastructure.agents.dialog_agent import DialogAgent from freya.infrastructure.messaging.message_bus import MessageBus # Initialize message_bus = MessageBus() dialog_agent = DialogAgent(message_bus, config) await dialog_agent.start() # Update chat endpoint @app.post("/api/chat") async def chat(message: dict): await message_bus.publish("dialog.request", { "message": message["message"] }) return {"status": "success"}

Enable Voice Button

# In app.py - Add endpoint @app.post("/api/speech/start") async def start_speech(): await message_bus.publish("speech.listen_request", {}) return {"status": "success"} # In index.html - Remove 'disabled' from button <button id="startListening" class="btn btn-outline full-width"> <span class="icon">🎤</span> Start Listening </button> # In app.js - Already has the handler ready!
