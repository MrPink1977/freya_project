# Scripts

Utility and debugging scripts for development and testing.

## Available Scripts

- `test_audio_devices.py` - Test audio device configuration
- `test_camera_integration.py` - Test camera/RTSP integration
- `test_debug.py` - General debugging utilities
- `test_dolphin_mixtral.py` - Test Dolphin Mixtral model
- `test_elevenlabs.py` - Test ElevenLabs TTS
- `test_freya_comprehensive.py` - Comprehensive system test
- `test_imports.py` - Verify all imports work
- `test_performance_tool.py` - Performance monitoring test
- `test_quick_tts.py` - Quick TTS test
- `test_text_mode.py` - Text interaction mode test
- `test_tts_comparison.py` - Compare TTS engines
- `test_wake_debug.py` - Wake word detection debugging

## Running Scripts

```bash
# From project root
python scripts/test_imports.py
python scripts/test_elevenlabs.py
```
