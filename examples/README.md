# Examples

Demo scripts showcasing Freya's capabilities.

## Available Demos

- `demo_facial_recognition.py` - Face detection and recognition demo
- `demo_personality_simple.py` - Personality system demonstration
- `demo_simple_face_detection.py` - Basic face detection
- `demo_tools.py` - Tool execution demonstration

## Running Examples

```bash
# From project root
python examples/demo_tools.py
python examples/demo_personality_simple.py
```
