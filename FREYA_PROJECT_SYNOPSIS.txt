║                          PROJECT OVERVIEW                              ║
╚═══════════════════════════════════════════════════════════════════════╝

FREYA is a sophisticated, JARVIS-style voice-enabled AI assistant built
with a modern event-driven agent architecture. She's designed as a
local-first, privacy-respecting conversational AI that combines:

  ✓ Voice Interaction      - Always-listening wake word detection
  ✓ Text Mode              - Terminal-based chat interface
  ✓ Multi-Agent System     - Event-driven microservices architecture
  ✓ Computer Vision        - Facial recognition & IP camera integration
  ✓ Smart Memory           - ChromaDB semantic search with auto-summarization
  ✓ Tool Integration       - 9 built-in tools (web, files, calc, system)
  ✓ Adaptive Personality   - Emotional intelligence with mood responses
  ✓ Clean Architecture     - Domain-driven design with clear layers
  ✓ Comprehensive Testing  - 494 test functions with CI/CD pipeline


═══════════════════════════════════════════════════════════════════════════
                          WHAT FREYA CAN DO
═══════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────┐
│ VOICE INTERACTION                                                   │
└─────────────────────────────────────────────────────────────────────┘

  • Wake Word Detection
    - Say "Hey, Freya" to activate (always listening in background)
    - Configurable sensitivity (0-1 scale)
    - 8-second session window after wake word
    - Fuzzy matching for natural variations

  • Speech-to-Text (STT)
    - Engine: Faster Whisper with GPU acceleration
    - Models: tiny/base/small/medium/large
    - Silent detection with configurable threshold
    - 30-second max recording with automatic cutoff
    - 16kHz sample rate for optimal quality

  • Text-to-Speech (TTS)
    - Local: Piper TTS (fast, on-device, free)
    - Cloud: ElevenLabs (high-quality, custom voice)
    - Pre-loaded phrases for instant response
    - Streaming synthesis during generation


┌─────────────────────────────────────────────────────────────────────┐
│ MEMORY & LEARNING                                                   │
└─────────────────────────────────────────────────────────────────────┘

  • Short-Term Memory
    - Rolling 12-turn conversation history
    - Automatic summarization at 80% capacity
    - Context-aware responses
    - Seamless multi-turn conversations

  • Long-Term Memory (ChromaDB)
    - Vector embeddings for semantic search
    - Embedding model: nomic-embed-text:latest (768-dim)
    - HNSW indexing for O(log n) retrieval speed
    - Persistent across sessions
    - Automatic storage of:
      * Names and birthdays
      * Likes and dislikes
      * Preferences and habits
      * Important facts and events

  • Memory Features
    - Importance levels (1-5 scale)
    - Metadata filtering
    - Corruption recovery
    - Top-3 similar memory recall
    - Auto-transfer from short to long-term at 75% capacity


┌─────────────────────────────────────────────────────────────────────┐
│ TOOLS & CAPABILITIES (9 Built-in Tools)                            │
└─────────────────────────────────────────────────────────────────────┘

  1. TIME & DATE
     • get_current_time - Current time in any timezone
     • get_current_date - Today's date (various formats)
     • calculate_time_until - Countdown to any date

  2. CALCULATIONS
     • calculator - Math expressions with scientific functions
       (supports sqrt, sin, cos, log, exp, factorial, etc.)

  3. FILE OPERATIONS
     • list_files - Directory listing with pattern matching
     • read_file - Read text files (with line limits)
     • write_file - Create/append to files

  4. WEB ACCESS
     • web_search - DuckDuckGo search with caching
     • web_scraper - Extract content from websites
       (text, titles, links, headings, custom selectors)

  5. SYSTEM INFO
     • system_info - OS, Python, disk usage, uptime
     • execute_command - Safe shell commands (whitelist only)

  Tool Features:
    ✓ Automatic detection via pattern matching
    ✓ 1-hour caching for web searches
    ✓ Rate limiting (10 req/min, burst 3)
    ✓ Circuit breaker for resilience
    ✓ Security whitelisting for sensitive operations


┌─────────────────────────────────────────────────────────────────────┐
│ PERSONALITY & EMOTIONAL INTELLIGENCE                                │
└─────────────────────────────────────────────────────────────────────┘

  Freya has a genuine personality with 8 customizable traits:

  • Directness (0.8)     - Blunt and honest, not overly diplomatic
  • Humor Level (0.7)    - Witty with friendly sarcasm
  • Empathy (0.7)        - Reads emotions and responds appropriately
  • Formality (0.2)      - Very casual and conversational
  • Verbosity (0.3)      - Concise by default (voice-optimized)
  • Curiosity (0.5)      - Balanced inquisitiveness
  • Sassiness (0.6)      - Playful sarcasm when fitting
  • Patience (0.8)       - Very patient and understanding

  Emotional Adaptation:
    → Detects user mood (happy, sad, frustrated, confused)
    → Matches energy level (excited → enthusiastic)
    → Adapts style (task-focused → efficient)
    → Shows genuine emotion (excitement, empathy, curiosity)


┌─────────────────────────────────────────────────────────────────────┐
│ VISION & CAMERA (Computer Vision)                                  │
└─────────────────────────────────────────────────────────────────────┘

  • Facial Recognition
    - Detection: HOG (CPU) or CNN (GPU)
    - Encoding: 5-point or 68-point landmarks
    - Storage: Directory-based known faces
    - Recognition tolerance: 0.5 (configurable)
    - Debouncing: 5-second minimum between recognitions

  • RTSP Camera Integration
    - Support: Reolink IP cameras + generic RTSP
    - ONVIF protocol for camera control
    - Multi-channel support
    - Real-time streaming
    - PTZ control capability


┌─────────────────────────────────────────────────────────────────────┐
│ WEB SEARCH                                                          │
└─────────────────────────────────────────────────────────────────────┘

  • Engine: DuckDuckGo (privacy-focused)
  • 1-hour result caching for efficiency
  • Rate limiting: 10 requests/minute
  • Trigger keywords:
    - search, google, look up, find
    - what is, who is, when did, how much
    - weather, news, latest, current
  • Configurable max results (default 5)

                          TECHNICAL ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────┐
│ EVENT-DRIVEN AGENT SYSTEM                                           │
└─────────────────────────────────────────────────────────────────────┘

  Freya uses a MessageBus pub/sub architecture with specialized agents:

       ┌─────────────────────────────────────────┐
       │   MessageBus (Async Pub/Sub System)     │
       │   • Priority queuing                    │
       │   • Backpressure handling               │
       │   • Event routing                       │
       └─────────────────────────────────────────┘
              │         │         │
              ▼         ▼         ▼
       ┌──────────┐ ┌──────────┐ ┌──────────┐
       │   Wake   │ │  Dialog  │ │  Memory  │
       │   Word   │ │  Agent   │ │  Agent   │
       │  Agent   │ │          │ │          │
       └──────────┘ └──────────┘ └──────────┘
              │         │         │
              ▼         ▼         ▼
       ┌──────────┐ ┌──────────┐ ┌──────────┐
       │  Speech  │ │   Tool   │ │  Coord-  │
       │  Agent   │ │ Executor │ │ inator   │
       │          │ │  Agent   │ │          │
       └──────────┘ └──────────┘ └──────────┘


  Agent Communication Flow:

    1. WakeWordAgent → Detects "Hey, Freya" → Publishes wake.detected
    2. SpeechAgent → Captures audio → Publishes speech.transcription
    3. ToolExecutorAgent → Detects tool needs → Executes tools
    4. MemoryAgent → Retrieves context → Returns relevant memories
    5. DialogAgent → Processes with LLM → Streams response
    6. SpeechAgent → Synthesizes speech → Plays audio


┌─────────────────────────────────────────────────────────────────────┐
│ CLEAN ARCHITECTURE LAYERS                                           │
└─────────────────────────────────────────────────────────────────────┘

  1. DOMAIN LAYER (freya/domain/)
     - Pure business logic (no external dependencies)
     - Entities: Memory, Fact, MemoryQuery
     - Interfaces: Agent, LLMClient, MemoryStore, MessageBus
     - Custom exceptions (20+ types)

  2. APPLICATION LAYER (freya/application/)
     - Use cases and coordinators
     - DTOs and event handlers
     - Business workflows

  3. INFRASTRUCTURE LAYER (freya/infrastructure/)
     - Model management (16GB VRAM optimization)
     - Memory system (ChromaDB + Nomic embeddings)
     - Agent implementations
     - Speech coordination (STT/TTS)
     - Tools and messaging

  4. PRESENTATION LAYER (freya/presentation/)
     - CLI interface (terminal UI)
     - Web UI (planned)

  5. SHARED LAYER (freya/shared/)
     - Structured logging with context
     - Resilience patterns (retry, circuit breaker)
     - Monitoring and observability


┌─────────────────────────────────────────────────────────────────────┐
│ TECHNICAL STACK                                                     │
└─────────────────────────────────────────────────────────────────────┘

  LLM & AI Models:
    • Main Model: dolphin3:8b (Ollama)
    • Reasoning: dolphin-mixtral:8x7b (complex queries)
    • Code: deepseek-coder-v2:16b-lite
    • Embeddings: nomic-embed-text:latest (768-dim)
    • Wake Detection: Whisper tiny
    • STT: Faster Whisper (base/small/medium)

  Speech & Audio:
    • STT: faster-whisper + ctranslate2
    • TTS Local: piper-tts
    • TTS Cloud: elevenlabs
    • Audio I/O: sounddevice, PyAudio

  Memory & Storage:
    • Vector DB: ChromaDB (HNSW indexing)
    • Embeddings: sentence-transformers
    • Optional: SQLite for debugging

  Core Python:
    • Python 3.11+
    • Async/await with asyncio
    • Type hints with pydantic
    • YAML configuration

  Tools & Utilities:
    • Web: requests, beautifulsoup4, ddgs
    • Vision: opencv-python, face-recognition
    • Camera: onvif-zeep
    • Testing: pytest (494 test functions)

    stt.sample_rate: 16000
    stt.silence_threshold: 0.02
    stt.silence_duration: 1.2

  Personality Traits (0-1 scale):
    personality.traits.directness: 0.8
    personality.traits.humor_level: 0.7
    personality.traits.empathy: 0.7
    personality.traits.formality: 0.2
    personality.traits.verbosity: 0.3

  OLLAMA_HOST=http://localhost:11434  # Ollama server override
  EMBEDDING_MODEL=nomic-embed-text     # Embedding model override
  MEMORY_PERSIST_DIR=data/memory       # Memory storage location

┌─────────────────────────────────────────────────────────────────────┐
│ RUNNING FREYA                                                       │
└─────────────────────────────────────────────────────────────────────┘

  # Default (voice mode with wake word)
  python main.py

  # Text mode (no voice)
  python main.py --mode text

  # Use Piper instead of ElevenLabs
  python main.py --engine piper

  # Override model
  python main.py --model llama3.2:3b

  # Custom config file
  python main.py --config config/custom.yaml

  # System checks only
  python main.py --check

  # Diagnostic mode (verbose)
  python main.py --diagnostic

                          QUICK START GUIDE
═══════════════════════════════════════════════════════════════════════════

  1. Install Ollama
     https://ollama.com/download

  2. Pull Required Models
     ollama pull dolphin3:8b
     ollama pull nomic-embed-text:latest

  3. Install Python Dependencies
     pip install -r requirements.txt

  4. Configure (Optional)
     Edit config/default.yaml to customize
     Create .env for ElevenLabs API key (optional)

  5. Run System Checks
     python main.py --check

  6. Start Freya
     python main.py                 # Voice mode
     python main.py --mode text     # Text mode

  7. Wake Freya (Voice Mode)
     Say: "Hey, Freya"
     Then ask your question

  8. Test Features
     - "What time is it?"
     - "Search for Python tutorials"
     - "Remember my birthday is January 1st"
     - "Calculate 2^8 + sqrt(144)"
     - "List files in the current directory"
